# Arsip Digital Sanggar Tari

## 1. Deskripsi Proyek

Proyek ini bertujuan untuk merancang sistem arsip digital sanggar tari yang digunakan untuk menyimpan dan mengelola dokumentasi kegiatan sanggar agar lebih rapi, mudah dicari, dan tidak mudah hilang.

## 2. Tujuan

* Menyimpan dokumentasi kegiatan sanggar tari secara digital.
* Memudahkan pencarian arsip berdasarkan nama kegiatan dan tanggal.
* Mengelola foto, video, audio, dan dokumen sanggar.

## 3. Jenis Data

1. **Data teks:** nama tarian, nama penari, tanggal kegiatan, dan deskripsi.
2. **Data gambar:** foto latihan, pertunjukan, dan kegiatan sanggar.
3. **Data audio:** rekaman musik pengiring tari.
4. **Data video:** rekaman latihan dan pertunjukan tari.
5. **Data 3D:** model tiga dimensi jika diperlukan untuk dokumentasi properti atau kostum.
6. **Data spasial:** lokasi sanggar atau lokasi pertunjukan.

## 4. Rencana Akuisisi Data

Data dikumpulkan dari dokumentasi sanggar, seperti catatan kegiatan, foto, rekaman audio, video, dan informasi lokasi. Setiap data diberi keterangan berupa nama kegiatan, tanggal, jenis data, dan sumber data.

## 5. Estimasi Penyimpanan

Estimasi awal penyimpanan menggunakan asumsi:

* 2.000 dokumen teks, masing-masing 2 KB.
* 1.000 foto, masing-masing 3 MB.
* 100 rekaman audio, masing-masing 20 MB.
* 100 video, masing-masing 500 MB.
* 20 model 3D, masing-masing 50 MB.
* 10 data lokasi, masing-masing 1 KB.

Total kebutuhan penyimpanan diperkirakan sekitar 54,69 GB. Dengan cadangan 30%, kapasitas yang disiapkan sekitar 71,10 GB.

## 6. Catatan

Angka jumlah data dan ukuran file merupakan asumsi untuk perencanaan, bukan hasil pengukuran arsip sanggar yang sebenarnya.
